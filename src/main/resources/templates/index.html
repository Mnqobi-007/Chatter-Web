About

About This Project

Chatter is a personal project built to learn how real-time systems work in practice — WebSocket messaging with STOMP, JWT-based authentication, and a Spring Boot backend talking to a relational database. It's a work in progress, not a finished product, and there are no real users on it yet beyond testing accounts. Feedback and code review are very welcome.
